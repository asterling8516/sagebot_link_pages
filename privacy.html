Privacy Policy

Last updated: September 16, 2026

1. Data Collection & Security

To provide its features, AI-Sage collects and temporarily stores the following information:

  • Guild (Server) IDs, Channel IDs, and User IDs: This identifier data is salted and securely stored in Firebase. It is never stored as plain text.
  • Message Content: The actual text of messages sent in the channels the bot has access to, and the bot's own responses, are the only data stored as plain text. The bot only reads new messages sent after it has been invited to the server.

2. Data Usage

The collected information is used strictly for bot functionality. Relevant message context is sent securely to the Gemini API to provide AI-powered D&D answers, generate timestamps, and create varied reminder messages.

3. Data Retention

We believe in minimizing data storage:

  • Guild Channels: Only the last 10 messages sent in an accessible guild channel are kept in memory for context.
  • Direct Messages (DMs): DMs sent directly to the bot are kept indefinitely.
  • Bot Messages: Messages generated and sent by the bot are kept for several months until they are no longer needed for context.
  • Server Removal: If the bot is removed from a server, all associated channel messages are deleted immediately.

4. Data Deletion Request

You have the right to request the deletion of your server's data at any time. To process this request, we require the Guild ID and proof of server ownership (e.g., a screenshot of your Discord server settings showing ownership).
